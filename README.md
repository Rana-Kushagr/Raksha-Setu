## 🌟 Why RakshaSetu Wins Competitions
In medical emergencies, the first **10 minutes ("The Platinum Minutes")** determine life or death. Most emergency apps fail because:
1. They require high-speed internet (fails in rural areas, basements, highway deadzones).
2. They require forced user registration/login.
3. They use dense medical jargon instead of actionable visual checklists.

**RakshaSetu solves this completely:**
- **Zero Login & Instant Load (<1 second)**.
- **100% Offline-Ready (PWA)**: All protocols, CPR metronomes, and medical IDs work with zero network.
- **Bilingual & Hands-Free**: High-stress readable UI with English & Hindi voice narration.

---

## ⚡ Core Features

1. **Interactive Emergency First-Aid Triage**:
   - Step-by-step verified action guides for Snakebites (Indian Cobra/Russell Viper), Heimlich Maneuver (Choking), Severe Arterial Bleeding & Tourniquet, 20-min Burn Cooling, Heatstroke, and Road Accidents.
   - Highlights critical **DOs** and **DONTs** (e.g. myth-busting on blade cuts / faith healing).
   - Audio Voice Narrator for hands-free guidance while performing first aid.

2. **Life-Saving CPR Rhythm Metronome**:
   - Precise **100–120 BPM** Web Audio oscillator sound beats and glowing pulse ring.
   - 30-compression counter with automatic "2 Rescue Breaths" prompt.

3. **1-Tap Community SOS & Live GPS Beacon**:
   - Uses `navigator.geolocation` for real-time high-accuracy GPS coordinates.
   - 1-click formatted emergency broadcast for WhatsApp, SMS, and native system sharing.

4. **Digital Medical ID (ICE - In Case of Emergency)**:
   - Saves blood group, emergency contacts, chronic conditions, and allergies locally.
   - Instant downloadable/printable Lockscreen Emergency Badge for first responders.

5. **AI Emergency Copilot**:
   - Answers emergency queries dynamically with an instant offline fallback to local medical protocols.

## 🚀 How to Run Locally

1. Open a terminal in this folder:
   ```bash
   npm start
   ```
2. Open your browser and navigate to `http://localhost:3000` (or simply double-click `index.html` in your file explorer).

---

## 🌐 1-Minute Free Deployment (Vercel / Netlify / GitHub Pages)

- **GitHub Pages**: Push this repository to GitHub, go to **Settings > Pages > Deploy from main branch**.
- **Vercel**: Run `npx vercel` or drag-and-drop the folder onto [vercel.com](https://vercel.com).
